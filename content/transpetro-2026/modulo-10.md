### Conjuntos e proporção

Os conjuntos se encaixam: naturais, inteiros, racionais e reais. Uma dízima periódica é racional; √2 e π são irracionais.

Compare potências com expoente comum. Exemplo: 2⁶ = (2³)² = 8² e 3⁴ = (3²)² = 9², então 3⁴ é maior.

Na regra de três composta, marque cada grandeza como direta ou inversa em relação à incógnita.

Exemplo: 3 torneiras enchem 180 m³ em 8 h, ou seja, 7,5 m³/h cada. Com 5 torneiras, 150 m³ levam 150 / 37,5 = 4 h.

Aumentos sucessivos multiplicam. Exemplo: +10% e depois +10% dão fator 1,21, ou +21%.

### Funções e equações

```latex
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \qquad x_1 + x_2 = -\frac{b}{a} \qquad x_1 x_2 = \frac{c}{a}
```

```latex
a^x = b \iff x = \log_a b \qquad \log(ab) = \log a + \log b \qquad \log a^n = n \log a
```

Exemplo exponencial: 3ˣ = 81 dá x = 4. Exemplo logarítmico: log₂ 32 = 5.

Exemplo de sistema: x + y = 11 e 3x + 2y = 28. Da primeira, y = 11 − x. Substituindo, x = 6 e y = 5. Então 2x + y = 17.

Trigonometria essencial: sen 30° = 1/2, cos 60° = 1/2, cos 30° = √3/2, sen 45° = √2/2 e tan 45° = 1. Sempre, sen²x + cos²x = 1.

### Análise combinatória

```latex
P_n = n! \qquad A_{n,p} = \frac{n!}{(n-p)!} \qquad C_{n,p} = \frac{n!}{p!\,(n-p)!}
```

A ordem importa? Se sim, arranjo. Se não, combinação.

Exemplo: escolher presidente e vice entre 5 pessoas dá 5 × 4 = 20. Escolher 2 entre 5 para uma comissão dá 10.

### Probabilidade

Probabilidade = casos favoráveis / casos possíveis. Eventos independentes multiplicam; excludentes somam.

Exemplo: dois dados somam 8 em 5 de 36 casos.

### Estatística

| Medida | Como obter |
| --- | --- |
| Média | Soma dos valores / quantidade |
| Mediana | Valor central dos dados ordenados |
| Moda | Valor mais frequente |
| Amplitude | Maior − menor |
| Variância populacional | Média dos quadrados dos desvios |
| Desvio padrão | Raiz da variância |

Exemplo: 2, 4, 6. Média = 4. Desvios: −2, 0 e 2. Variância = 8/3. Desvio padrão ≈ 1,63.

Se todos os valores são iguais, o desvio padrão é zero.

### Matemática financeira

```latex
J = C\,i\,t \qquad M = C(1 + i\,t) \qquad M_{comp} = C(1 + i)^t
```

Exemplo: R$ 2.000 a 5% ao mês por 2 meses. Simples: M = 2.200. Compostos: M = 2.205.

Taxa mensal equivalente, com M/C conhecido e n meses: i = (M/C)^(1/n) − 1. Para achar k em porcentagem, multiplique i por 100.

### Armadilhas de prova

- Somar porcentagens sucessivas em vez de multiplicar fatores.
- Calcular o tempo de ida com velocidades médias erradas: use d = v·t para as duas viagens.
- Em "x ≤ x²", lembrar que números entre 0 e 1 são maiores que seus quadrados.
- Esquecer de dividir por 2 a área do triângulo.
